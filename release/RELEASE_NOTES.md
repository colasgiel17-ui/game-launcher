## Nouveautés
- 🎮 Nouvelle icône manette pixel art
- DS / 3DS : la fenêtre « Commandes » affiche les touches PC du jeu ; touches par défaut posées si melonDS n'en avait aucune
- Restaurer une sauvegarde ouvre directement le jeu sur cette sauvegarde
- Fenêtre de jeu contenue + barre (taille, commandes, CPU, Quitter et sauvegarder)
- Limitation de puissance sans crépitement audio
- Première version Linux

## Installation
- **macOS** : décompresser `GameLauncher-macOS.zip` → *Applications* → clic droit › Ouvrir
- **Linux** : `tar xzf gamelauncher-linux.tar.gz && cd gamelauncher-linux && ./install.sh`
